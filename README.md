<h1 align="center">💼 Java Payroll Management System</h1>

<p align="center">
A simple <b>Java OOP based Payroll Management System</b> that manages employee salary details and demonstrates core Object-Oriented Programming concepts.
</p>

<hr>

<h2>📌 Project Overview</h2>

<p>
The <b>Java Payroll Management System</b> is a console-based application developed using the Java programming language.
It is designed to manage employee information and automatically calculate salaries based on employee type.
</p>

<p>
This project demonstrates the practical implementation of core <b>Object-Oriented Programming (OOP)</b> concepts such as:
</p>

<ul>
<li>Encapsulation</li>
<li>Inheritance</li>
<li>Abstraction</li>
<li>Polymorphism</li>
</ul>

<p>
Payroll systems are commonly used in organizations to manage employee records and salary calculations efficiently while reducing manual work and errors. <sup>📚</sup>
</p>

<hr>

<h2>🚀 Features</h2>

<ul>
<li>Add Full-Time Employees</li>
<li>Add Part-Time Employees</li>
<li>Calculate Employee Salary</li>
<li>Remove Employees</li>
<li>Display Employee Details</li>
<li>Object-Oriented Design</li>
<li>Simple Console Interface</li>
</ul>

<hr>

<h2>🛠 Technologies Used</h2>

<ul>
<li>Java</li>
<li>Object-Oriented Programming (OOP)</li>
<li>ArrayList for Data Storage</li>
<li>Java Collections Framework</li>
</ul>
